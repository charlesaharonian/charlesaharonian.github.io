# Rosace

Calculateur de moiré prépresse. **Page web autonome** : un seul fichier HTML, aucun serveur, aucun compte, aucune installation.

## Utiliser en ligne

**https://charlesaharonian.github.io/**

## Utiliser hors-ligne

1. Téléchargez [`index.html`](./index.html)
2. Ouvrez-le dans Chrome, Safari, Firefox ou Edge (double-clic)

Les réglages restent dans le navigateur.

## Ce que calcule Rosace

Le moiré du 1er ordre entre trames AM (encres CMYK, pantone, anilox hexagonal, mesh, capteur scanner). Période, écart d’angle, contraste d’encre, rosace ISO 12647.
